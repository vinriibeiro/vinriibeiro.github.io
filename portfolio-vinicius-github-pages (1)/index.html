02 / PROJETO DE CIÊNCIA DE DADOS

Projeto pessoal · Brasileirão 2018–2025

Além do Placar.

Construí este projeto para desenvolver minhas habilidades em Ciência de Dados. Analisei 3.040 partidas com dados abertos e reuni estatística, Machine Learning, Power BI e uma central de perguntas em português — cada resposta vem com a fonte.

No teste de 2025, o erro do modelo foi de 0,48 ponto por jogo, contra 0,57 da referência simples. Melhor, mas ainda é estimativa, não certeza. Uma hipótese minha também não se confirmou.

Duas regras: nada é inventado e toda resposta mostra de onde veio.

05 / MÉTODO DE TRABALHO

Como eu trabalho.

Requisitos, arquitetura, desenvolvimento, revisão e testes com responsabilidades definidas. Uso agentes de IA como apoio técnico e mantenho a aprovação humana nas decisões de entrega.

Ideia→PRD→Arquitetura→Desenvolvimento→Revisão→QA→Validação→Aprovação
  • PRD, tarefas e critérios de aceitação documentados por projeto.
  • Branches por tarefa, commits pequenos e até três ciclos de correção.
  • Testes e auditoria com evidências; nenhum resultado inventado.
  • Merge e deploy somente após minha aprovação.
